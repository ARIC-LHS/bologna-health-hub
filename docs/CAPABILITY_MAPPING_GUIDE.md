# Capability Mapping Guide v1.0

## Principle

Capabilities describe the type of expertise or contribution offered to a topic.

They do not describe academic disciplines, departments or affiliations.

Each Contribution should normally have 1–3 capabilities.

Do not create new capabilities unless a substantial number of Contributions cannot be classified using the current taxonomy.
